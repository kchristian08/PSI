Exercício

Crie uma aplicação web para apresentar uma página inicial e permitir que um usuário envie seu nome por um formulário. A aplicação deve possuir navegação entre páginas e exibir uma mensagem personalizada após o envio do formulário.

Requisitos:
Página Inicial: 👍
Mensagem de boas vindas
Parágrafo com texto explicando o projeto.
Link para uma página de cadastro
Cadastro: 
Deve exibir uma mensagem “Cadastro”
Deve incorporar um formulário com um campo apenas
O campo deve solicitar o nome do usuário
Deve ter um botão de submissão de formulário
Página de Resposta
Deve exibir o nome enviado
Deve possuir um link para voltar para página inicial
