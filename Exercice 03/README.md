Exercício 03


Metodologia de desenvolvimento da atividade: Programação em Pares.
Duas pessoas vão resolver o problema. Uma pessoa assume o papel de driver, que programa o projeto. A outra pessoa da equipe assume o papel de navigator, que assume o papel de orientador, verificador da lógica e possíveis erros do projeto. 

Esse papel deve ser alternado durante a tarefa. A dupla troca de papel.

Tarefa
Crie um programa que exige uma página inicial com título: cadastro de atletas para os jogos intercurso.

Requisitos:
Página Inicial: 
link para modalidade vôlei
link para modalidade futebol
Cadastro Futebol:
Formulário para cadastro (por simplicidade não vamos distinguir gênero)
Nome da turma
Nome da equipe
Capitão/capitã
Página Mostrar equipe Futebol
Apresentar um cabeçalho h1 com o nome da turma
Apresentar um cabeçalho h2 com o nome da equipe
Parágrafo com o nome do capitão
Aplicar CSS no projeto
Adicionar CSS no projeto
O CSS não deve ser adicionado ao código HTML.
Incluir mecanismo de login e logout básicos
Controle por meio de variável
Salvar os dados do usuário em arquivo no sistema (DESAFIO)
aplicar redirecionamento.

Entrega:
Quando for entregar o projeto, remover a pasta do ambiente.
Compactar o restante do código e adicionar a tarefa do GSA.
Informar o nome dos participantes da equipe.
