Exercício 04


Metodologia de desenvolvimento da atividade: Programação em Pares.
Duas pessoas vão resolver o problema. Uma pessoa assume o papel de driver, que programa o projeto. A outra pessoa da equipe assume o papel de navigator, que assume o papel de orientador, verificador da lógica e possíveis erros do projeto. 

Esse papel deve ser alternado durante a tarefa. A dupla troca de papel.

Tarefa
Refatore o projeto App2, que possui o recursos abaixo:
templates
base.html
páginas filhas com extends
blocos com block
CSS carregado com url_for
Objetivo
O sistema deve continuar com um estilo visual padrão nas páginas gerais, mas a página de cadastro deve receber uma aparência própria, diferente das demais.
Essa mudança deve ser feita sem quebrar a organização do App2 e sem copiar toda a estrutura HTML novamente.
Requisitos da atividade
Etapa 1 — Criar um novo estilo para o cadastro
Crie um estilo visual específico para a página de cadastro. Esse estilo pode ser:
escrito por você;
adaptado de um modelo;
gerado com ajuda de IA e depois ajustado por você.
Etapa 2 — Aplicar esse estilo somente no cadastro
Você deve modificar o Projeto 2 para que:
o estilo geral continue funcionando nas outras páginas;
o novo estilo afete apenas a página cadastro.html.
