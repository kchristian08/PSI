Exercício 05 - Tratamento de Erros

Metodologia de desenvolvimento da atividade: Programação em Pares.
Duas pessoas vão resolver o problema. Uma pessoa assume o papel de driver, que programa o projeto. A outra pessoa da equipe assume o papel de navigator, que assume o papel de orientador, verificador da lógica e possíveis erros do projeto. 

Esse papel deve ser alternado durante a tarefa. A dupla troca de papel.

Tarefa
Objetivo: aplicar o tratamento de erros utilizando mensagens flask e abort. 

Descrição da atividade:

Baixar o arquivo Exemplos.zip.
Identificar situações onde é possível aplicar a função abort + errorhandler para tratar erros do sistema
Identificar situações onde é possível aplicar o uso da função flash para enviar informações para o usuário diante de erros como (senha incorreta entre outros).
Alterar o código para incorporar implementações referentes às duas situações identificadas conforme descrito anteriormente.
